# Aerial Radio para Kodi

> **Criador:** [@TrainAgain2](https://github.com/TrainAgain2)

Um catálogo de rádios ao vivo para Kodi: encontre emissoras por país, género, tema ou nome e guarde as suas favoritas.

## Instalação

1. Abra a [release mais recente](../../releases/latest).
2. Baixe `plugin.audio.aerial.radio-0.5.1.zip`.
3. No Kodi, use **Add-ons → Instalar a partir de ficheiro ZIP**.
4. Abra **Aerial Radio Catalog** na secção de add-ons de música.

## Funções

- Pesquisa de rádios por nome, país, género e tema.
- Rádios populares, recentes e em português.
- Favoritos locais.
- Coleções para relaxar, focar, conduzir, treinar e mais.
- Catálogo local incluído para utilização estável.
